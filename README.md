Power BI Project – Ride Booking Analysis Dashboard (Uber/Ola)

📌 Project Overview

This project presents an interactive Ride Booking Analysis Dashboard built using Power BI.
The dashboard provides insights into ride bookings, customer activity, trip performance, weather conditions, and pricing trends for cab services like Uber/Ola.

It helps users analyze ride patterns, monitor customer behavior, and understand operational performance through interactive visualizations.

---

🛠️ Steps Followed

1. Imported the ride booking dataset into Power BI
2. Cleaned and transformed the data using Power Query
3. Created calculated measures and KPIs
4. Built visualizations for ride analysis and customer insights
5. Added interactive charts and filters
6. Designed dashboard layout with a professional theme

---

📈 Key Insights

- Certain cities generate higher ride revenue
- Completed trips are higher than cancelled trips
- Ride pricing varies based on trip status and location
- Weather conditions influence ride activity in some regions
- Wind speed and humidity data provide environmental insights related to rides
